# Finance_V4 — Mapping Factory pipeline

Generated by **Mapping Factory · Deploy-as-Pipeline**. This repo is a Databricks Asset
Bundle (DAB) with a Spark Declarative Pipeline that materializes the mapping's targets.

- **Pipeline:** `finance_v4_pipeline`
- **Target:** `pritam_demo_workspace_catalog.mapping_factory_pipeline` · materialization: **materialized_view**
- **Config:** `config/mapping_config.json` (deterministic transforms + data-quality rules + joins)
- **Code:** `src/mapping_pipeline.py` (generic, config-driven — do not hand-edit transforms)

## Deploy
```bash
databricks bundle validate
databricks bundle deploy -t prod
```

## How it works
The pipeline reads `mapping_config.json`, registers each source table as a view, LEFT-JOINs
them on the configured keys, applies the compiled transform SQL per target column, and
attaches the data-quality rules as pipeline expectations. Regenerate the config from
Mapping Factory rather than editing SQL by hand.
